# Developmental Checklist Application

Ang proyektong ito ay isang interactive web-based utility na idinisenyo upang subaybayan at i-dokumento ang iba't ibang aspeto ng pag-unlad ng isang indibidwal. Nagbibigay ito ng isang sistematikong paraan para sa mga guro, magulang, o mga eksperto upang masuri ang mga kakayahan at progreso sa iba't ibang yugto.

## Mga Larangan ng Pag-unlad (Developmental Domains)
* Receptive & Expressive Language: Pag-unawa at pagpapahayag sa pamamagitan ng wika.
* Cognitive: Kakayahang mag-isip, matuto, at lumutas ng mga suliranin.
* Self-help: Mga pang-araw-araw na gawaing pansarili at sariling-sikap.
* Social-Emotional: Pakikitungo sa kapwa at pamamahala sa sariling emosyon.

## Mga Pangunahing Tampok (Features)
* Evaluation Phases: May nakalaang monitoring para sa Pre-Test, Mid-Test, at Post-Test upang masubaybayan ang pagbabago at progreso sa paglipas ng panahon.
* List Generation: Kakayahang awtomatikong buuin ang kabuuang checklist o listahan batay sa mga napiling indicators.
* Quick Data Management: Nilalaman nito ang mabilis na mga function tulad ng pag-clear ng data para sa bagong assessment at pag-kopya ng resulta (copy to clipboard) para sa madaling pag-uulat.

## Teknolohiya (Tech Stack)
* HTML5
* CSS3
* JavaScript
