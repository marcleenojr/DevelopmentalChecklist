# DevelopmentalChecklist
Isang interactive Developmental Checklist app para subaybayan ang pag-unlad ng bata sa wika, kognitibo, self-help, at sosyo-emosyonal na aspeto. Sinusuportahan nito ang Pre, Mid, at Post-Test monitoring na may tampok para mag-clear, mag-generate, at mag-copy ng listahan para sa mabilis at sistematikong pag-assess ng mga guro at magulang.
